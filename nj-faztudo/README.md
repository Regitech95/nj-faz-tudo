# NJ Faz Tudo — Site Institucional de Serviços Domésticos
Site responsivo para apresentação de serviços de manutenção, reparos e serviços gerais para residências, com animação de carregamento e formulário de contato via WhatsApp.

## 🚀 Funcionalidades
- Página inicial com animação de carregamento personalizada da marca
- Seção de apresentação dos serviços: elétrica, hidráulica, montagem de móveis, manutenção de caixa d'água, reparos gerais e suporte em tecnologia
- Botão de contato direto com mensagem pré‑preenchida para o WhatsApp
- Links para redes sociais: Instagram e Facebook
- Layout responsivo, compatível com computadores e celulares
